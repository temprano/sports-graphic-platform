## Consent Flags Reference

| Flag | Description | Risk Level |
|------|-------------|------------|
| backgroundRemoval | BiRefNet cutout | Low |
| colorAdjustment | Exposure/color grade | Low |
| poseAdjustment | AI pose reposition for layout | Medium |
| aiMotion | Synthetic motion from still (head turn etc.) | High |
| marketingUse | Use in platform portfolio/samples | Medium |

All flags default to `false`. Must be explicitly opted in.
Minor players (under 18) require parent/guardian to sign.

## Order State Machine

```
PENDING_PAYMENT
  → [deposit webhook received] → IN_PRODUCTION

IN_PRODUCTION
  → [all renders complete] → PENDING_PROOF_REVIEW

PENDING_PROOF_REVIEW
  → [customer approves] → PROOF_APPROVED
  → [customer requests changes] → PROOF_REVISION_REQUESTED

PROOF_REVISION_REQUESTED
  → [re-render complete] → PENDING_PROOF_REVIEW

PROOF_APPROVED
  → [balance invoice sent] → PENDING_FINAL_PAYMENT

PENDING_FINAL_PAYMENT
  → [balance webhook received] → PAID_IN_FULL

PAID_IN_FULL
  → [fulfillment triggered] → FULFILLMENT

FULFILLMENT
  → [delivery confirmed] → DELIVERED

Any state → [dispute/chargeback] → DISPUTED
```

## Parent Order States

```
PENDING_PAYMENT → PROCESSING → FULFILLED → DELIVERED
```

Parent orders do not require proof approval — they are produced
from already-approved team order assets.
